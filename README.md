# forgesport
E-commerce full-stack de material deportivo para gimnasio y vóley, creado con React, Node.js, Express, MongoDB y CSS puro como proyecto de aprendizaje y portfolio.

## Documentación

Cada commit genera su entrada en `docs/changelog/` con un hook local (Git + Gemini). En un clon nuevo:

```
git config core.hooksPath .githooks
setx GEMINI_API_KEY "tu_clave"
```

La documentación se publica en GitHub Pages desde `develop`.
